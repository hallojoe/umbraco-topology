Setup & run your cluster
Prerequisites: .NET 10, Aspire CLI, Python 3, Node.js 22+, and your selected container runtime. Trust the local HTTPS development certificate.
The commands start CM, CD1 and CD2, wait for readiness, and describe the running environment. Run aspire stop --non-interactive from the generated project directory to stop it.
Only need a single Umbraco instance? Use Umbraco CMS or Umbraco Cloud instead.
